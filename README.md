# מצרכים בבית

אפליקציה לניהול המצרכים בבית, לפי האפיון שב־[home-grocery-spec.md](home-grocery-spec.md) ולפי חבילת העיצוב.

| קובץ | מה יש בו |
|---|---|
| `index.html` | האפליקציה כולה בקובץ אחד: מסכים, לוגיקה וזיהוי חשבוניות |
| `Code.gs` | קוד השרת ב־Google Apps Script: שמירה בגיליון, לשוניות שבועיות, מיילים וארכיון חשבוניות ב־Drive |

## הרצה מהירה, בלי התקנה

פותחים את `index.html` בדפדפן. הנתונים נשמרים במכשיר, ונתוני הדגמה של משפחת כהן נטענים אוטומטית.

## חיבור ל־Google Sheets (שיתוף בין בני הבית)

1. יוצרים Google Sheet חדש בשם "מצרכים – משפחת …".
2. בתפריט: **הרחבות ← Apps Script**.
3. מדביקים את התוכן של `Code.gs` לקובץ `Code.gs`.
4. מוסיפים קובץ HTML בשם `index` (‏**+ ← HTML**), ומדביקים בו את כל התוכן של `index.html`.
5. **פריסה ← פריסה חדשה ← אפליקציית אינטרנט**:
   - הפעלה בתור: **אני**
   - גישה: **כל מי שיש לו חשבון Google**, או רק משתמשי הדומיין
6. **לצ'אט עם הסוכן:** ב־Apps Script פותחים **הגדרות הפרויקט** (גלגל השיניים) ← **מאפייני סקריפט** ← **הוספת מאפיין**. שם המאפיין: `GEMINI_API_KEY`, והערך: מפתח ה־Gemini API. המפתח לא נכתב בקוד.
7. מאשרים את ההרשאות (גיליון, Drive, מייל, וגישה לשירות חיצוני) ושולחים לבני הבית את קישור ה־‎/exec. אפשר להוסיף אותו למסך הבית בטלפון.
8. אופציונלי: מריצים פעם אחת את `installTrigger` כדי לקבל תזכורת יומית במייל ביום הפקת הרשימה.

**מה קורה בגיליון:**
- לשונית נסתרת `_data` שומרת את כל הנתונים. היא מקור האמת.
- הלשוניות `קטלוג`, `מלאי`, `משפחה`, `חשבוניות` ו־`יומן` נכתבות מחדש בכל שמירה.
- לכל שבוע נפתחת לשונית `רשימה DD.MM` עם תיבות סימון. אם מסמנים V, מוסיפים שורה (שם פריט בעמודה "פריט") או מוחקים שורה בגיליון, השינוי נקלט באפליקציה תוך כ־20 שניות. כך גם שינוי בעמודת הכמות בלשונית `מלאי`.
- אם שני אנשים עדכנו את אותו נתון באותו זמן, המערכת ממזגת את השינויים לפי פריט, והעדכון האחרון לכל פריט הוא שנשמר.
- המיילים נשלחים לכתובות שהוזנו בפרופיל המשפחה.
- תמונות החשבוניות נשמרות בתיקייה "חשבוניות מצרכים" ב־Drive.

## מה כלול (לפי האפיון)

- **פרופיל משפחה:** גיל מחושב מתאריך הלידה, וקבוצת הגיל מתעדכנת לבד, עם התראה כשהיא משתנה. אפשר לערוך את מקדמי הצריכה לפי גיל ולפי קטגוריה. אחרי כל שינוי מוצגת ההשפעה הצפויה ("הצריכה צפויה לעלות בכ־8%"). יש הרשאות לפי תפקיד.
- **קטלוג:** הוספה, עריכה, מחיקה, איחוד כפולים, ייבוא משורות שמודבקות מגיליון, כינויים בחשבוניות, מוצר מועדף וחלופות. המינימום מחושב אוטומטית, ואפשר לקבוע מינימום ידני.
- **מלאי:** סינון לפי מיקום וקטגוריה, חיפוש, כפתורי +/−, כפתור "נגמר" עם אפשרות ביטול, עריכה מדויקת של כמות, תוקף ומיקום. פריט שיורד מתחת למינימום נכנס לרשימה אוטומטית. כל שינוי נרשם ביומן: מי, מתי ומה היה הערך הקודם.
- **רשימה שבועית:** הכמות מחושבת לפי הנוסחה: צריכה צפויה לפי הפרופיל, משוקללת עם הצריכה בפועל, ועוד מלאי ביטחון, פחות מה שיש בבית. היא מעוגלת לאריזות שלמות, ולכל פריט מוצגים סיבה ומחיר משוער. אפשר להוסיף פריט ידני או חופשי, לשנות כמות, להסיר ולהחזיר, ולהעביר פריט לשבוע הבא. יש "מצב סופר" (טקסט גדול, והמסך לא נכבה) ואישור שנועל גרסה שבועית.
- **חשבוניות:** צילום, תמונה מהגלריה או PDF. הזיהוי (OCR) בעברית רץ בדפדפן עם Tesseract. כל שורה מותאמת לקטלוג, ומוצג מסך אישור עם שורות "זוהו", "לא זוהו" ו"לא רלוונטי". התאמות שתוקנו ידנית נלמדות לפעם הבאה, ומתקבלת אזהרה על חשבונית כפולה. המחירים נשמרים.
- **היסטוריה:** מדדים חודשיים, הוצאה, הפריטים שנגמרים הכי מהר, ארכיון חשבוניות והיסטוריית מחירים.
- **הגדרות:** יום ושעה להפקת הרשימה, מלאי ביטחון, התראות, ערכת צבעים כהה או בהירה, ייצוא וגיבוי מלא (JSON או CSV).
- **צ'אט עם הסוכן:** כפתור ירוק עגול בכל מסך פותח שיחה עם סוכן Gemini (`gemini-flash-lite-latest`). כל שאלה נשלחת יחד עם המלאי העדכני ורשימת הקניות, כדי שהסוכן יוכל לענות אם מצרך קיים בבית או שצריך להוסיף אותו לרשימה. מצרכים שהסוכן מזכיר, שנגמרו ועוד לא ברשימה, מוצגים ככפתורי "+ לרשימה". מעליו יש כפתור כתום "טסט" שפותח צ'אט טסט נפרד, על הדגם `gemini-3.1-flash-lite`, עם הנחיה משלו ("כל שאלה שאתה מקבל תחזיר לי את המילה טסט") ובלי נתוני הבית. ההנחיות של שני הסוכנים מוגדרות ב־`AGENTS`, גם ב־`Code.gs` וגם ב־`index.html`. כשהאפליקציה פתוחה כקובץ מקומי, הצ'אט מבקש להדביק מפתח, והוא נשמר במכשיר בלבד.
